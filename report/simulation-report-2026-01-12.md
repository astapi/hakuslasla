# 戦闘シミュレーション分析レポート

**実行日**: 2026-01-12
**対象**: 装備セット × パッシブプリセット の組み合わせ検証

---

## エグゼクティブサマリー

### 主な発見

1. **毒特化ビルドは全ダンジョンで勝率0%** - 深刻なバランス問題
2. **クリティカル特化は序盤のみ有効** - 中盤以降急激に弱体化
3. **回復特化・防御特化が最も安定** - 全ダンジョンで高勝率
4. **吸血特化は中盤まで有効** - 後半ダンジョンでは厳しい
5. **速度特化は変動が大きい** - ダンジョンによって有効/無効が分かれる

### 推奨ビルド

| 進行度 | 推奨ビルド | 理由 |
|--------|-----------|------|
| 序盤 (Lv.5-10) | 任意 | 全ビルドで攻略可能 |
| 中盤 (Lv.15-25) | 回復特化 or 吸血特化 | 安定した勝率 |
| 終盤 (Lv.30-50) | 回復特化 + DEF装備 | 唯一の安定攻略法 |

## バランス問題のまとめ

### 🔴 深刻な問題

| 問題 | 影響 | 推奨対応 |
|------|------|---------|
| **毒特化が全ダンジョンで0%** | 毒ビルドが完全に死んでいる | 毒ダメージの大幅増加、または毒の追加効果（スロー等） |
| **終盤の選択肢がない** | 回復・防御以外でクリア不可 | 敵のスケーリング調整、または他ビルドの終盤強化 |
| **吸血特化の急落** | Lv.35→40で100%→14% | スケーリングの見直し |

### 🟡 中程度の問題

| 問題 | 影響 | 推奨対応 |
|------|------|---------|
| **クリティカルの弱体化** | 中盤以降ほぼ機能せず | クリダメージ倍率の増加、またはクリ時追加効果 |
| **速度特化の不安定さ** | ダンジョンごとに有効/無効が変動 | スケーリングの一貫性を持たせる |
| **クリア時間の極端な差** | 回復・防御は遅いが確実、攻撃系は早いが不安定 | リスク/リターンのバランス調整 |

### 🟢 良好な点

| 項目 | 詳細 |
|------|------|
| 序盤のバランス | Lv.5ダンジョンは全ビルドで攻略可能 |
| 回復・防御の一貫性 | 全ダンジョンで安定してクリア可能 |
| 装備とパッシブの相乗効果 | DEF装備 + 防御/回復パッシブの組み合わせが有効 |

## 改善提案

### 1. 毒特化の救済（優先度: 高）

```
現状: 毒ダメージが敵HPに対して不十分
改善案:
- 毒ダメージを敵最大HPの%ダメージに変更
- 毒スタックによるダメージ増加
- 毒状態の敵への追加ダメージボーナス
```

### 2. 終盤スケーリングの調整（優先度: 高）

```
現状: 敵のステータス上昇が回復・防御以外のビルドを無力化
改善案:
- 敵ステータスの上昇曲線を緩やかに
- プレイヤーの攻撃系ステータスのスケーリング強化
- 終盤装備のMOD効果を強化
```

### 3. クリティカルビルドの強化（優先度: 中）

```
現状: クリティカル発生しても火力不足
改善案:
- クリティカル時の追加効果（出血、貫通等）
- クリティカルダメージ倍率の上方修正
- クリティカル率に応じた追加ボーナス
```

### 4. 速度特化の安定化（優先度: 中）

```
現状: ダンジョンごとに有効/無効が変動
改善案:
- 攻撃速度による回避率ボーナス
- 速度が高いほどゲージ有利を得られる仕組み
- 連続攻撃時のダメージボーナス
```

## 結論

現在のバランスは**回復・防御特化に極端に偏っている**。プレイヤーは実質的にこの2つのビルド以外の選択肢がなく、ゲームの多様性が損なわれている。

特に毒特化の完全な機能不全は早急な対応が必要。また、終盤コンテンツにおけるビルドの多様性確保も重要な課題である。

攻撃的なプレイスタイル（クリ特化、速度特化、吸血特化）で高リスク・高リターンの戦略が成立するよう、バランス調整を推奨する。
