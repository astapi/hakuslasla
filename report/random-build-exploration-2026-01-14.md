# ランダムビルド探索レポート

作成日: 2026-01-14

## 概要

手動で定義したプリセット以外の「意図しない強ビルド」を発見するため、ランダムにパッシブノードを選択して大量のビルドをシミュレートし、OPビルドの傾向を分析した。

## 作成スクリプト

### 1. `scripts/exploreBuilds.ts`

ランダムビルド探索スクリプト。

**機能:**
- `requiredNodes`を尊重した有効なランダムビルド生成
- 各ダンジョン × 装備タイプ(ATK/DEF/CRIT/POISON) の組み合わせでシミュレート
- OPビルド(勝率95%+)の頻出ノードを分析
- 全ダンジョンのサマリー出力

**設定:**
```typescript
buildsPerDungeon: 500    // 各ダンジョンで生成するランダムビルド数
runsPerBuild: 100        // 各ビルドのシミュレーション回数
winRateThreshold: 0.95   // OPビルドとみなす勝率閾値
```

**使用方法:**
```bash
npx tsx scripts/exploreBuilds.ts
```

### 2. `scripts/analyzeFinalLandBuilds.ts`

終焉の地クリアビルドの詳細分析スクリプト。

**機能:**
- クリアビルドのパッシブ効果、装備ステータス、MOD効果の内訳出力
- 最終ステータス計算の詳細表示
- クリアビルドの平均値サマリー

**使用方法:**
```bash
npx tsx scripts/analyzeFinalLandBuilds.ts
```

## 発見された問題点

### 1. vamp_1 (吸血の心得) が突出して強い

- OPビルドの **93%** に含まれている
- 効果: `ATK+5, HIT時HP+20回復`
- 序盤で取得可能なのに効果が高すぎる

**調整案:**
- HIT時HP+20 → HIT時HP+10 に弱体化
- または、より深いノードに移動

### 2. 序盤〜中盤が簡単すぎる

- Lv5〜30のダンジョンで平均勝率85〜100%
- 特に氷結の洞窟(Lv25)が97%と簡単すぎる

**調整案:**
- 敵のステータス強化
- ダンジョン階層数の増加

### 3. DEF装備が有利すぎる

- OPビルドの29%がDEF装備（最も高い）
- ATK装備は21%（最も低い）

**調整案:**
- DEF装備のMODを調整
- ATK装備の攻撃系MODを強化

### 4. 特化ビルドが不要

- 毒final、クリfinalなどの深いノードを取得せずともクリア可能
- 汎用的な浅いノードの組み合わせが最強

**調整案:**
- 深いノードの効果を強化
- または序盤ノードを弱体化

## 今後の活用方法

1. **定期実行**: バランス調整後に再度探索スクリプトを実行して効果を確認
2. **閾値調整**: OPビルド閾値(95%)や弱ビルド閾値(30%)を調整して分析
3. **特定ノード除外**: 特定ノードを除外した場合の勝率変化を分析
4. **敵強化シミュレーション**: 敵ステータスを変更した場合の影響を確認
