## 計算式補足

### increased% と more% の違い

```
最終値 = 基本値 × (1 + total_increased%) × (1 + more1%) × (1 + more2%) × ...
```

- **increased%**: 加算で合計される（例: 20% + 30% = 50% increased）
- **more%**: 乗算で適用される（例: 15% more × 20% more = 1.15 × 1.20 = 1.38倍）

### 攻撃速度の計算例

Lv.50 速度特化の場合:
- 基本攻撃速度: 1.0
- increased: 88%
- more: 35% (15% + 20%)

```
最終攻撃速度 = 1.0 × (1 + 0.88) × (1 + 0.35) = 1.0 × 1.88 × 1.35 = 2.538
```

約2.5倍の攻撃速度となる。
