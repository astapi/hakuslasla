## Phase 4: コミュニティ・プラットフォーム投稿

### 4-1. Product Hunt

- [ ] https://www.producthunt.com/posts/new にアクセス
- [ ] Product URL に App Store リンクを入力
- [ ] タイトル: `LootDive`
- [ ] タグライン（60文字以内）: `Auto-battle hack & slash RPG - just gear up and dive in`
- [ ] スクリーンショット・YouTube動画を添付
- [ ] First Comment を準備して投稿
- [ ] 投稿タイミング: 週末の 12:01 AM PT（日本時間 17:01）が理想

**注意:**

- 「Upvoteしてください」は NG → 「見てコメントしてください」と依頼
- コメントには積極的に返信する
