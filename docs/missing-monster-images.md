## 画像追加手順

1. `assets/images/monsters/` に画像ファイル（PNG）を配置
2. `data/images.ts` の `monsterImages` にエントリを追加:
   ```typescript
   export const monsterImages: Record<string, ImageSourcePropType> = {
     // 既存...
     new_monster_key: require('@/assets/images/monsters/new_monster.png'),
   };
   ```
3. `monsters.json` の該当モンスターの `image` フィールドが正しいキーになっていることを確認
