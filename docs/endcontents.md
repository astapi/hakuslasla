エンドコンテンツの仕様

終焉の地をクリア
→ エンドコンテンツ( 異次元ラッシュダンジョンの解放）

異次元ラッシュ: 1~200階まで
50階にゴブリンキング
70階に盗賊の頭
90階にヴァンパイア
110階にクラーケン
120階に魔王
200階に終焉の王

各ボスを倒すとUber versionのボスが解放される。
50階のゴブリンキングを倒すと、Uberゴブリンキングが解放
各ボスは専用ユニークアイテムをドロップする

各ボスが低確率でUberボスの入場券をDropする

Uberボスは更に強力な専用ユニークアイテムをドロップする

→ 装備MODを厳選し、パッシブツリーを見直し、強力な専用ユニークを取り入れて200階の終焉の王を倒すことがエンドコンテンツの最終目標

異次元ラッシュでの敵テーブルとステータス

- 120階までは魔王城までのモンスターからランダムに出現
- ステータスは終焉の地のモンスター相当
- 121階からは魔王城の次から終焉の地までのモンスターからランダムに出現
- ステータスは終焉の地から1.2倍程度
- 150階からはステータスは更に1.2倍程度
- 180階からはステータスは更に1.2倍程度

異次元ラッシュのボスについて

各ボスに通常攻撃以外のスキルを持たせる。
ステータスも大幅に強化

ゴブリンキング
- スキル: ゴブリンたちの咆哮
    - 配下のゴブリンたちの咆哮でゴブリンキングの攻撃力UP
    - プレイヤーの攻撃力ダウン

盗賊の頭
- スキル: ベアトラップ
    - プレイヤーのAS低下

ヴァンパイア
- MOD: ヒット時HP回復+100　を持つ
- スキル: 血の狂宴
    - 血の雨が降り注ぎ、プレイヤーに毒を付与

クラーケン
- MOD: AS + 20%
- MOD: 毎秒HP回復+100
- スキル: 津波
    - ダメージ + DEFデバフ

魔王
- スキル: デスハンド
    - HP回復+1000
    - プレイヤーに毒を付与
- MOD: ダメージ軽減+2% を持つ

終焉の王
- スキル: 終焉
    - HP回復+2000
    - ATK+100% でダメージ
- MOD: 毎秒HP回復+200
