## ビルド評価

### Tier S（最安定）
1. **DEF+回復特化** - 全ダンジョン100%勝率。最も安定したビルド。
2. **DEF+防御特化** - LV25以降は100%勝率。硬さで押し切る。

### Tier A（高勝率）
3. **ATK+吸血特化** - 序盤〜中盤で100%。高レベルダンジョンでは厳しい。
4. **POISON+毒特化** - LV40以降で真価を発揮。終盤ダンジョンで100%。

### Tier B（条件付き有効）
5. **ATK+速度特化** - 中レベル帯で有効だが不安定。
6. **CRIT+クリ特化** - 火力は高いが生存力不足。勝率が安定しない。

## 推奨ビルド

### 初心者向け
- **DEF装備 + 回復パッシブ**: 時間はかかるが確実にクリア

### バランス型
- **ATK装備 + 吸血パッシブ**: 序盤〜中盤で高効率

### 終盤特化
- **POISON装備 + 毒パッシブ**: 高レベルダンジョンで最強

### 速度クリア
- **ATK装備 + 速度パッシブ**: 適正レベル帯なら最速

---

## まとめ

1. **安定性重視**: DEF+回復 が全レベル帯で最も安定
2. **毒ビルドの復権**: LV40以降で毒ダメージ吸収により強力に
3. **クリティカルの限界**: 高レベルでは生存力不足が露呈
4. **パッシブLV40が転換点**: 多くのビルドがLV40パッシブで安定化
5. **終盤は毒・防御・回復**: 速度・吸血系は高レベルで厳しい
