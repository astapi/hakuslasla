## 高優先度（リリース前に必須）

### 1. 法的・ストア要件

- [ ] **プライバシーポリシーの作成**
  - 収集するデータの明示（ローカルストレージ、広告ID等）
  - Webページとして公開し、URLを取得
  - `app.json` への設定追加

- [ ] **サポート連絡先の用意**
  - メールアドレスまたはWebフォーム
  - ストア掲載用URL

- [ ] **利用規約の作成**（任意だが推奨）

### 2. ストアメタデータ

- [ ] **アプリ説明文**
  - 日本語版（メイン）
  - 英語版（グローバル展開時）

- [ ] **スクリーンショット準備**
  - iOS: 6.5インチ、5.5インチサイズ
  - Android: 16:9比率推奨
  - 最低5枚、戦闘・装備・スキルツリー等を含む

- [ ] **プロモーション動画**（任意）
  - 既存の `output.mp4`, `output2.mp4` を編集

- [ ] **レーティング設定**
  - App Store: 年齢制限の申告
  - Google Play: コンテンツレーティング質問票への回答

- [ ] **カテゴリ設定**
  - ゲーム > ロールプレイング

### 3. コード品質

- [ ] **console.log の整理**
  - 開発用ログ約380箇所を確認
  - 本番不要なログを削除または `__DEV__` ガード追加
  ```typescript
  if (__DEV__) {
    console.log('debug info');
  }
  ```

- [ ] **エラーハンドリング強化**
  - DB操作失敗時のユーザー向けメッセージ
  - ネットワークエラー時のリトライUI（広告読み込み等）

- [ ] **TypeScript型チェック通過**
  ```bash
  npx tsc --noEmit
  ```

- [ ] **ESLint警告の解消**
  ```bash
  npm run lint
  ```

### 4. テスト

- [ ] **iOS実機テスト**
  - iPhone SE（小画面）
  - iPhone 15 Pro等（大画面）

- [ ] **Android実機テスト**
  - 低スペック端末（2GB RAM）
  - 高スペック端末

- [ ] **全画面フローの動作確認**
  - キャラクター作成 → ダンジョン攻略 → レベルアップ → 装備変更

- [ ] **長時間プレイテスト**
  - メモリリークの確認
  - バトルログ蓄積による遅延確認

## ビルド・提出

### EASビルド

```bash
# プレビュービルド（内部テスト用）
eas build --profile preview --platform all

# 本番ビルド
eas build --profile production --platform all
```

### ストア提出

```bash
# App Store Connect / Google Play Console へ提出
eas submit --platform ios
eas submit --platform android
```

### バージョン管理

- `app.json` の `version` を更新
- `eas.json` の `autoIncrement` でビルド番号自動増加
